# microsteps.mx

Divulgar ciencia murmurando. Ciencia desde México.

Una sola página que cuenta una historia: una pregunta, la murmuración (cada punto sigue a sus 7 vecinos más cercanos, como los estorninos) y los lentes para mirarla: naturaleza, ciencia, psicología, neurociencia, educación, espiritualidad, chamanismo y masculinidad.

- Fotos: Carlos, sin datos de ubicación.
- Diseño: iwi.
- Fuentes: Reynolds, 1987 (SIGGRAPH); Ballerini y otros, 2008 (PNAS 105:1232); Mech, 1999 (Canadian Journal of Zoology 77:1196); Beggs y Plenz, 2003 (Journal of Neuroscience); Isha Upanishad, verso 6; Jacobo Grinberg, teoría sintérgica.

Se publica con GitHub Pages desde la rama `main`. El archivo `CNAME` liga el sitio a microsteps.mx.
