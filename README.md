# microsteps.mx

Divulgar ciencia murmurando. Ciencia desde México.

Una sola página: una murmuración que sigue la regla de los estorninos (cada punto mira a sus 7 vecinos más cercanos) y seis lentes para mirarla: naturaleza, psicología, ciencia, educación, chamanismo y masculinidad.

- Fotos: Carlos, sin datos de ubicación.
- Diseño: iwi.
- Fuentes: Reynolds, 1987 (SIGGRAPH); Ballerini y otros, 2008 (PNAS 105:1232); Mech, 1999 (Canadian Journal of Zoology 77:1196).

Se publica con GitHub Pages desde la rama `main`. El archivo `CNAME` liga el sitio a microsteps.mx.
